# 01 · Designs

The visual reference for **BMU Campus Eats** lives in [Figma](https://www.figma.com/design/pOPskhvCKVF6aPYKMedHs5/BMU-CAMPUS-EATS?node-id=3-1141). Access depends on its sharing settings. This folder contains design documentation and repository artwork, not an export of the editable Figma file.

## Visual direction

Warm cream surfaces pair with espresso text and terracotta accents. Headings use **Playfair Display**; interface and body text use **Poppins**, loaded through Google Fonts.

| Colour | Hex | Use |
| :--- | :--- | :--- |
| Cream | `#F8EFE3` | Page background |
| White | `#FFFFFF` | Card surfaces |
| Espresso | `#321C18` | Primary text |
| Terracotta | `#B94B32` | Accents |
| Paprika | `#98351F` | Stronger accents |
| Beige | `#E9CBAA` | Secondary details |
| Muted grey | `#70645D` | Supporting text |

Implementation lives in [site.css](../02-frontend/styles/site.css), with base layout in [design.css](../02-frontend/styles/design.css) and separate page styles. The home interaction lives in [water-surface.js](../02-frontend/scripts/water-surface.js).
